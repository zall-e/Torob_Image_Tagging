# Image Captioning with Gemma

This project uses **Google’s Gemma VLM** to generate **image captions and descriptive tags** automatically.  
It takes an image as input and produces relevant **tags** as output.

The goal of this project is to extract meaningful textual descriptions from images using a large language model with visual understanding.  
Our system uses **Gemma** for multimodal reasoning — enabling it to “see” images and “describe” what it sees.

**Key features:**
- Generate high-quality image captions  
- Extract descriptive tags for categorization or search  
- Easily integrate into datasets or APIs  

---

## Model

We use the **Gemma-3-4B-Instruct** model as the vision-language backbone.  
The model receives both image and text inputs and produces structured text outputs such as captions or tags.

**Workflow:**
1. Load and preprocess image  
2. Encode image into embeddings  
3. Feed embeddings to the Gemma model with an instruction prompt (e.g., “Describe this image”)  
4. Parse and clean output text into tags and captions  

---

## Preprocessing Pipelines

We developed two separate but connected preprocessing systems — one for images and one for text.

### Image Dataset Pipeline
- Collected all raw images. 
- Resized every image to **256×256 pixels** for uniform model input.  
- Uploaded the cleaned and resized dataset to **Hugging Face Datasets Hub** for easy access and version control.  

**Steps:**
1. Load and validate image paths  
2. Resize to 256×256
3. Convert and save to optimized formats (e.g., `.jpg`)  
4. Upload to Hugging Face using `datasets` or `huggingface_hub`  

### Text Dataset Pipeline

The text data (captions, tags, and metadata) was stored as a JSON file and processed through a dedicated cleaning pipeline before loading into Redis.

**Pipeline steps:**
1. Load raw JSON file
2. Remove invalid or duplicate entries
3. Store the cleaned dataset in Redis for efficient query

**Purpose of Redis:**

Acts as a fast key-value store for text–image mappings
Enables distributed processing and parallel evaluation
Simplifies integration with the Gemma inference loop
